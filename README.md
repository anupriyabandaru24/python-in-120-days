# Python in 120 Days

My journey learning Python from beginner to job-ready, following a structured 120-day mentorship roadmap.

## Structure

Each week is a folder containing:
- Daily concept notes and coding challenges
- Mini projects applying that week's concepts
- Growing toward larger capstone projects in later phases

## Progress

- ✅ **Week 1** — Functions (`*args`, `**kwargs`, defaults, scope), string methods & f-strings, error handling (`try/except`), file I/O, modules/pip/venv basics. Capstone: CLI to-do list app with file persistence.
- 🔄 **Week 2** — Data structures (lists, tuples, sets, dicts), comprehensions. *In progress.*

## Tech
Python 3.x, Git/GitHub for version control.

## Roadmap
Following a 120-day plan covering: Python fundamentals → OOP → testing → APIs & databases → web basics (Flask/FastAPI) → data structures & algorithms → interview prep.
